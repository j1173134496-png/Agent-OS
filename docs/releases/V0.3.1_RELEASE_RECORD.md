## Scope

V0.3.1 corrects the employee-facing model entry point. It keeps only the
approved text models, adds the verified reasoning selector, hides the relay
endpoint and Agent-suffixed model duplicates, and removes the legacy floating
capability entry from the active runtime.

Approved text models:

- `GPT-5.6 Sol` -> `gpt-5.6-sol`
- `GPT-5.6 Terra` -> `gpt-5.6-terra`
- `GPT-5.6 Luna` -> `gpt-5.6-luna`
- `GPT-5.5` -> `gpt-5.5`

The default text model is `gpt-5.5`. The image tool remains configured with
`gpt-image-2`; the image model is not exposed in the text model selector.

## Reasoning Contract

The relay probe selected the OpenAI-compatible Chat Completions protocol with
`reasoning_effort`. The probe accepted `low`, `medium`, and `high` for all four
approved models and received a streaming response. The Responses protocol also
returned a successful standalone probe and remains available for future policy
selection.

## Rollback

The V0.3.0 image was recreated from the pinned rollback digest and returned
HTTP 200/`OK`. The API service was then recreated with the V0.3.1 digest.
MongoDB collection counts and upload file count/total bytes were unchanged.
The rehearsal also created a MongoDB archive and configuration backup without
copying `.env` or API keys. Details are in
`deployment/runtime/v0.3.1/rollback-report.json` and
`deployment/runtime/v0.3.1/rollback-backup/backup-manifest.json`.

The retired V0.3.0 overlay is isolated under
`deployment/rollback/v0.3.0/` and is not loaded by the active Compose file.
