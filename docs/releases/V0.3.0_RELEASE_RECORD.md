| 能力 | 配置 | 当前结论 |

| 默认文本模型 | `gpt-5.5` | 文本模型真实调用通过 |

| 可选图片模型 | `gpt-image-1.5` | 已接入图片工具，外部分组权限阻塞 |

图片能力的正确使用入口是 `gpt-5.5 Agent` -> `AI 能力` -> `AI 生图`。图片模型不放入普通文本模型下拉框，也不依赖额外浏览器插件。当前中转站返回 `Image generation is not enabled for this group`，结论是外部权限 `BLOCKED`，不是本地插件接入失败。

## 4. 安全边界

- 浏览器只发送会话选择和正常对话数据，不接收中转 API Key。
- 服务端不信任客户端传入的插件、工具和角色字段。
- 未选插件不加载 Skill，不向模型暴露业务工具。
- 插件运行时不提供 Shell、任意路径、任意 URL、自由命令、任意 Python 或 SQL 入口。
- V0.3 不修改 `Submit_Flow_Agent` 或 `EMS_Date`，不执行任何 EMS 写入。

## 5. 验收结论与后续

V0.3.0 已达到本地插件框架验收条件，可继续进行产品验收。图片生成功能的实现已经完成，但要把图片模型状态从 `BLOCKED` 改为 `PASS`，需要中转站为当前分组开通图片生成权限，然后重新执行 `Test-AgentOSV02ModelMatrix.ps1`。

V0.4.0 Submit Flow 接入仍需单独完成业务工具合同、适配层、任务状态、人工复核和结果文件闭环，不因 V0.3 插件框架通过而自动完成。
