## 1. 交付内容

- 立能派 Agent OS 标题、中文登录界面、Logo、Favicon 和应用图标。
- 首屏 HTML 标题、描述、中文语言、主题色和品牌资源缓存版本化。
- LibreChat 配置服务端挂载，端点限制为 `custom`。
- 中转 API 配置同步脚本，缺少参数时安全地生成空端点并标记 `BLOCKED`。
- 本机运行、品牌、端点隔离和安全检查脚本。

- 五个文本模型和两个图片模型的白名单配置；图片工具支持两个图片模型并默认使用 `gpt-image-2`。
- 模型矩阵验证脚本，区分文本模型通过、图片接口通过和中转分组权限阻断。
- V0.2 全量 Gate 汇总命令和 `gate-report.json`。

## 5. 进入 READY 所需输入

用户需将以下信息放入本机私密 `.env`，不在聊天、文档或 Git 中发送：

- 公司中转 API Base URL（已配置于本机 `.env`）。
- API Key（已配置于本机 `.env`）。
- 文本与图片模型 ID（已配置于本机 `.env`）。
- 协议类型：`chat_completions` 或 `responses`。

补齐后执行 `Sync-AgentOSV02Config.ps1`、重启服务，再执行能力探针和 20 轮回归。只有对应 JSON 报告为 `PASS`，才能进行用户验收。
