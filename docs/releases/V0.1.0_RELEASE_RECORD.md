## AgentOS 变更

- 新增 Windows PowerShell 启停、状态、日志和健康检查脚本。
- 固定 Web 端口为 `3080`，不使用 `3000`。
- 只向宿主机发布 `localhost:3080`。
- MongoDB、上传目录、日志目录和索引数据使用本地持久化目录。
- `.env` 只由本机生成，不进入 Git。
- 不接入公司中转 API、业务插件、MCP Adapter 或真实业务数据。
