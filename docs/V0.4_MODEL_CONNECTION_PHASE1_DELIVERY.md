# V0.4 阶段 1：模型连接中心交付说明

## 交付范围

本阶段完成公司 LLM 中转站的服务端配置、URL 规范化、默认模型验证和可用模型验证。API Key 只从私有 `.env` 读取，运行报告会脱敏，不会写入仓库。

## 配置

在 `K:\Workers\AgentOS\.env` 设置：

```text
AGENTOS_LLM_BASE_URL=http://192.168.124.3:3000
AGENTOS_LLM_API_KEY=...
AGENTOS_LLM_MODEL=gpt-5.5
AGENTOS_LLM_MODELS=gpt-5.5,gpt-5.6-sol,gpt-5.6-terra,gpt-5.6-luna
AGENTOS_LLM_PROTOCOL=chat_completions
```

Base URL 可以带或不带 `/v1`，验证脚本会统一去除尾部 `/v1`，请求固定使用 `/v1/models` 和 `/v1/chat/completions`，避免 `/v1/v1`。

## 验证命令

```powershell
Set-Location K:\Workers\AgentOS
.\scripts\Test-AgentOSModelConnection.ps1
```

报告输出到 `deployment/runtime/model-connection-report.json`。成功条件是：模型列表请求成功、默认模型 `gpt-5.5` 在列表中、最小 Chat Completions 请求成功。

## Agent 模型策略

`deployment/agents/smart-submit-v1.json` 已固定智能填报助手使用 `gpt-5.5`，并关闭用户模型覆盖。平台配置的其他模型只有在通过验证后，才可加入 Agent 的 `allowed_models` 白名单；Submit 的 OCR、校验、计算和 Excel 生成不依赖用户模型选择。

## 未包含内容

本阶段不包含网页任意本地路径读取、不包含多站区批处理，也不把 API Key 暴露给普通用户。模型连接中心的可视化管理员页面可在本脚本验证通过后接入，避免先做页面而无法确认后端链路。
